# Brian Aross — Portfolio

Personal portfolio, built from scratch during the McTaba Labs full-stack programme.

**Live site:** https://arossbrian-creator.github.io/portfolio/

## Built with

HTML, CSS (custom properties, Flexbox, Grid, media queries) and GitHub Pages. No frameworks or JavaScript yet.

## Structure

- `index.html` — the page
- `portfolio_css/style.css` — all styling
- `images/` — portrait and assets
